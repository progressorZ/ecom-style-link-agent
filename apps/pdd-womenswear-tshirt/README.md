# 拼多多女装 T 恤上新助手

把一款女装 T 恤的标题、属性、颜色尺码、价格库存、尺寸表和图片录入一次，助手会自动填写拼多多商品编辑页并回读核对，商家检查后手动发布。

这是一个面向最终用户的独立工具，只包含拼多多中国站女装 T 恤所需的录入和自动化流程。普通用户不需要理解 Adapter、JSON、Node.js 或 Playwright。

## 下载后怎么用

1. 完整解压对应系统的 ZIP，不要在压缩包内直接运行。
2. Windows 双击 `Start-PDD-Assistant.cmd`；macOS 双击 `Start-PDD-Assistant.command`。
3. 在自动打开的工作台中录入商品；第一次可以先载入完整示例。
4. 打开商家浏览器并登录，进入拼多多女装 T 恤的新商品编辑页。
5. 点击“检查资料并载入”及“填写并核对”，最后由商家检查并发布。

当前一次处理一款商品，支持多颜色、多尺码、价格库存、尺码模板、主图、颜色图、详情图、发货和现有运费模板。验证码、平台新增必填项、商品内容真实性和最终发布由商家处理。

发布物按操作系统分开：

- Windows 10/11 x64：独立便携 ZIP。
- macOS：独立便携 ZIP，当前实验版同时包含 Apple Silicon 与 Intel 运行时。

该 App 使用自己的 `dataNamespace`，不得读取其他表单 App 的商品资料、浏览器 profile 或任务记录。更新同一 App 时可以迁移该 App 的 data；不同 App 之间不直接复制 data 目录。

详细说明见仓库根目录的 [`使用说明.md`](../../使用说明.md)。
