# 拼多多童鞋板鞋上新助手

这是拼多多中国站“童鞋/婴儿鞋/亲子鞋 > 板鞋 > 板鞋”的实验性单款资料工作台。它把商品属性、颜色鞋码、价格库存、尺码表和图片集中录入，减少反复抄写，并生成可供后续 Adapter 使用的结构化草稿。

> 当前状态为 `experimental`。本地资料整理功能可用，真实拼多多页面自动填写尚未启用。Windows 和 macOS 便携包也标为实验性，只提供当前本地能力，不应被当作已通过平台验收的正式版本。工作台不会自动发布商品。

## 当前可以做什么

- 录入商品货号、标题、品牌和童鞋板鞋属性。
- 使用欧码、英码、通用码或自定义童鞋尺码，生成颜色×鞋码规格矩阵和 SKU 编码。
- 逐规格填写拼单价、单买价和库存，或从 Excel/WPS 整表导入、粘贴。
- 记录参考价、满件折扣、脚长/脚宽尺码表及是否同步到详情。
- 管理主图、商品辅助图、包装标签图、详情图和每色规格图的本机副本。
- 记录发货时效、偏远地区模板名称和基础服务意图。
- 保存多个商品模板；套用为新商品时生成新货号和新 SKU。
- 下载业务资料备份，以及导出不可执行的商品草稿 JSON。
- 在专用商家浏览器中只读采集属性下拉选项；采集不会填写、保存或发布。

## 开发者启动

项目根目录需要 Node.js 24.15 或以上版本：

```sh
npm install
npm run build
npm run workbench:start
```

打开 <http://127.0.0.1:5173/?app=pdd-board-shoes>。源码开发环境也可以先运行 `npm run dev`，但图片复制、自动编号、备份和专用浏览器需要本机工作台后台同时运行。

普通用户如使用 Release 中的实验性便携包，必须下载与系统对应的板鞋包、完整解压后从包内启动，不要在压缩包预览窗口中直接运行。便携包仍不会启用板鞋真实页面自动填写。

## 推荐使用流程

1. 初次使用可点击“载入完整初始示例”，了解字段结构；示例价格、库存、属性和图片不能用于销售。
2. 直接填写商品资料，或下载板鞋导入模板后从 `.xlsx`、`.csv`、`.tsv` 导入。旧版 `.xls` 需先另存为 `.xlsx`。
3. 确认颜色和鞋码，生成规格矩阵与尺码表。脚长、脚宽必须来自供应商资料或已确认的试穿结果，系统不会推算。
4. 填写双价格、库存、参考价、折扣，选择自己的商品图片，并检查发货与服务意图。
5. 点击“检查全部资料”，处理全部阻塞项后导出商品草稿 JSON。该文件不会直接执行平台填写。
6. 如需采集平台选项，点击“打开专用商家浏览器”，登录并进入类目 ID `201517965903` 的发布页，再回到工作台点击“自动采集下拉选项”。

## Excel/WPS 表格

每行代表一个“颜色＋鞋码”组合。必需列为：`颜色`、`鞋码`、`拼单价`、`单买价`、`库存`。`商品货号`、`商品标题`、`品牌`、`参考价`、`满2件折扣`及童鞋属性可以只在第一条规格行填写。图片和脚长/脚宽尺码表目前在工作台中补充。

## 数据与隐私

商品草稿和模板保存在当前浏览器的本机存储中；图片副本、备份内容和采集报告保存在本机工作台数据目录。专用商家浏览器的登录状态独立保存，不包含在业务资料备份中。不要把使用后的 `data` 目录、未脱敏报告或真实商品图片提交到仓库或发送给他人。详见项目的[隐私说明](../../PRIVACY.md)。
