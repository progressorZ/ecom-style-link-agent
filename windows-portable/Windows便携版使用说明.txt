拼多多上新助手 Windows 便携版

适用系统：Windows 10/11 64 位。

作用：
把女装 T 恤的标题、属性、颜色尺码、价格库存、尺寸表和图片录入一次，助手自动填写拼多多商品编辑页并回读核对。你负责登录、验证码、检查商品并点击最终发布。

完整流程：
准备商品资料 → 工作台录入或复用模板 → 登录拼多多 → 自动填写并核对 → 手动发布

第一次使用：
1. 将整个 ZIP 解压到普通文件夹，例如 D:\拼多多上新助手。不要在压缩包内直接运行。
2. 双击“Start-PDD-Assistant.cmd”。运行环境已包含在 ZIP 中，不需要额外下载；程序会自动打开本地工作台网页。
3. 在工作台填写真实商品资料；第一次不会填时，先点击“载入完整初始示例”，再逐项替换。
4. 点击“检查资料并载入”，再点击“打开商家浏览器”。优先使用 Google Chrome；没有 Chrome 时使用 Windows 自带的 Microsoft Edge。
5. 在专用浏览器登录拼多多，进入“女装/女士精品 → T 恤 → T 恤”的新商品编辑页。
6. 回到工作台点击“填写并核对”。检查平台页面后由本人手动发布。

日常使用：
- 每次只打开一个“Start-PDD-Assistant.cmd”窗口，启动窗口需要保持打开。
- 商品资料、模板、图片副本、任务报告和专用浏览器登录状态都在 data 文件夹中。请定期备份整个 data 文件夹。
- 更新版本时，先关闭助手，将旧版 data 文件夹复制到新版根目录，再启动新版。

排错：
- 启动失败：双击“Diagnose-PDD-Assistant.cmd”。
- 如果启动窗口曾退出，错误会保存在 data\startup-error.log，可以把该文件发给维护人员；不要发送整个 data 文件夹。
- 浏览器打不开：确认 Edge 或 Chrome 可以正常启动，关闭遗留的助手浏览器后重试。
- 端口被占用：关闭其他助手窗口，或重启电脑后再运行。
- Windows 安全提示：包内 node.exe 来自 Node.js 官方发行包，并在构建时校验 SHA-256；项目启动脚本没有商业代码签名。请从官方 Release 下载原始 ZIP 并核对随包 SHA-256。
- 如果提示缺少 runtime\node.exe，请检查是否完整解压、Windows 安全中心“保护历史”是否隔离了它。不要关闭安全软件；确认来源可信后按系统提示处理。
- 不建议通过微信等会改写或删除压缩包内容的工具转发；请直接分享官方 Release 下载链接。

隐私：
- 工作台只监听本机 127.0.0.1，不对局域网或互联网开放。
- 新便携包不包含制作者的店铺资料、商品图片或登录状态。
- 不要把使用后的 data 文件夹发给别人，其中可能含店铺资料及登录状态。
