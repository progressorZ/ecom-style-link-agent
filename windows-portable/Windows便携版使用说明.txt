电商上新助手 Windows 免安装版

适用系统：Windows 10/11 64 位。

本 ZIP 已包含运行程序和依赖，启动时不需要从网上下载 Node.js 或 npm 包。当前 App 的具体用途、已支持功能和限制请先阅读同目录 README-App.md。

第一次使用：
1. 将整个 ZIP 解压到普通文件夹，例如 D:\电商上新助手。不要在压缩包预览窗口中直接运行。
2. 双击 Start-PDD-Assistant.cmd。黑色启动窗口需要保持打开，程序会自动打开只在本机访问的工作台网页。
3. 按 README-App.md 的流程录入资料。需要商家页面时，使用工作台打开的专用浏览器登录；验证码、滑块和最终发布始终由本人处理。
4. 工作台标为“实验性”或“尚未启用自动填表”的 App 只整理本地资料，不会填写平台页面。

日常使用：
- 同一个 App 每次只打开一个启动窗口。不同 App 会自动使用各自的本机端口和数据目录。
- 商品资料、模板、图片副本、任务报告和专用浏览器登录状态保存在 data 文件夹。
- 更新同一个 App 时，先关闭助手并使用工作台的一键备份；也可备份整个 data 文件夹。不要把其他 App 的 data 目录混用。

排错：
- 启动失败：双击 Diagnose-PDD-Assistant.cmd。
- 启动窗口退出后，查看 data\startup-error.log。可以只发送这个错误文件给维护者，不要发送整个 data 文件夹。
- 商家浏览器打不开：确认 Microsoft Edge 或 Google Chrome 可以正常启动，关闭遗留的助手浏览器后重试。
- 提示端口被占用：关闭其他助手窗口，或重启电脑后再运行。
- 提示缺少 runtime\node.exe：压缩包未完整解压，或文件被传输工具/安全软件删除。请从项目官方 GitHub Release 重新下载原始 ZIP并核对 SHA-256，不要关闭安全软件。

隐私：
- 工作台只监听本机 127.0.0.1，不向局域网开放。
- 新包不包含制作者的店铺资料、商品图片或登录状态。
- 使用后的 data 文件夹可能包含账号登录状态和商品资料，不要分享给别人。
