# 拼多多童鞋板鞋 Adapter

该 Adapter 面向拼多多中国站类目 `201517965903`：**童鞋/婴儿鞋/亲子鞋 > 板鞋 > 板鞋**。当前状态为 `experimental`。

本地工作台已经实现基础资料、类目属性、颜色×童鞋尺码矩阵、SKU 编码、双价格、库存、脚长/脚宽尺码表、商品图片、发货与服务意图、商品模板、表格导入、备份和安全草稿导出。这些能力只证明本地数据流程可以运行，不代表拼多多页面写入已经验证。

## 当前边界

- 页面截图已经确认主要字段、颜色与尺码结构、尺码表、素材区、价格库存和基础服务。
- 专用商家浏览器提供只读选项采集，不选择或修改平台字段。
- 属性选项、平台必填性、字段联动、确定性选择器、保存草稿、重开和独立回读仍待真实页面验证。
- 编译结果始终保持 `executable: false`；不得调用女装 T 恤执行器填写板鞋页面。
- 不自动点击最终发布，也不提供多商品批量上架。

开发页：`http://127.0.0.1:5173/?app=pdd-board-shoes`

页面合同见 [`config/pdd/board-shoes-v1.json`](../../config/pdd/board-shoes-v1.json)，证据和验收边界见 [`docs/60-pdd-board-shoes-discovery.md`](../../docs/60-pdd-board-shoes-discovery.md)。
