# v0.1.5 Beta 发布说明

本版把项目从单一女装工具进一步整理为可扩展的多 App 仓库，并首次提供拼多多童鞋板鞋实验包。

## 用户可见变化

- 女装 T 恤与童鞋板鞋分别构建 Windows x64 和 macOS 通用免安装 ZIP；每个包只启动自己的前端、后台、Adapter 和数据目录。
- 四个 ZIP 均内置 Node.js 运行时与 npm 依赖，启动时不在线下载程序文件。商家登录和访问拼多多页面仍需要网络。
- 板鞋工作台支持完整初始示例、Excel/WPS 导入、多个商品模板、多个尺码表模板、多颜色鞋码规格、双价格库存、脚长脚宽尺码表、图片、服务意图、备份和不可执行草稿导出。
- 板鞋专用浏览器可以只读采集当前类目的下拉选项；采集结果保存在本机并用于表单选择，不会填写、保存或发布平台商品。
- 商品草稿使用稳定素材编号，导入后会检查本机图片是否仍存在；发行包同时包含 App 使用说明与隐私说明。

## 工程与安全

- CI 自动运行前端测试、全部脚本测试、两个 App 的隔离构建和生产编译。
- Release 工作流分别在 Windows 与 macOS runner 上构建并执行干净数据目录启动检查，再生成 SHA-256。
- 新增 App manifest 的前后端入口、包内文档和数据隔离契约，以及 Profile、页面合同和 Adapter 的跨文件语义检查。
- 新增 Dependabot 与 CODEOWNERS 配置。工作台继续只监听 `127.0.0.1`，自动发布保持关闭。

## 当前边界

女装 T 恤仍为 `beta`。童鞋板鞋为 `experimental`：本地资料工作台和便携包可运行，但真实拼多多页面写入、平台草稿保存、重开与独立回读尚未通过实页验证，因此板鞋自动填表保持关闭。

发行文件：

- `pdd-womenswear-tshirt-v0.1.5-windows-x64.zip`
- `pdd-womenswear-tshirt-v0.1.5-macos-universal.zip`
- `pdd-board-shoes-v0.1.0-windows-x64.zip`
- `pdd-board-shoes-v0.1.0-macos-universal.zip`

每个 ZIP 均附带同名 `.sha256` 文件。
