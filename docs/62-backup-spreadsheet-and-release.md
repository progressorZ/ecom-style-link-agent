# 本机备份、商品表格导入与自动发行

## 一键备份与恢复

女装和板鞋工作台均提供“备份与恢复本机资料”。备份文件包含工作台中的商品草稿、模板、店铺与运费设置、任务报告、图片副本，以及浏览器页面保留的当前录入。恢复完成后关闭启动窗口并重新打开程序。

备份不包含拼多多专用浏览器的登录目录。登录状态可能包含账号凭据，而且浏览器运行时文件会被占用；升级同一台电脑上的便携版时，应保留原程序的 `data/.runtime/pdd-workbench-profile`，不要发送给其他人。

## Excel/WPS 商品导入

工作台可下载 CSV 模板，也可以读取 `.xlsx`、`.csv`、`.tsv`。旧版 `.xls` 需先另存为 `.xlsx`。一行代表一个颜色和尺码组合，必需列为颜色、尺码或鞋码、拼单价、单买价、库存。商品货号、标题、品牌、参考价、折扣和类目属性可以只在第一行填写。

导入不会猜测图片、尺码表或缺失属性。工作台保留没有出现在表格中的当前值，导入后仍须运行“检查全部资料”。

## GitHub 自动发行

`.github/workflows/release.yml` 支持手动运行构建，也会在推送 `v*` 标签时构建完整 Windows 和 macOS 便携包。标签运行成功后，工作流会创建对应 GitHub Release，并上传 ZIP 与 SHA-256 文件。

发布示例：

```bash
git tag v0.1.5
git push origin v0.1.5
```

手动运行只生成 Actions Artifacts，不创建 GitHub Release；标签触发才会公开发行。
