# 接下来可以做的事项

## 先完成用户手动验收

不用自动发布，不重复全量上传来修复单字段差异。每例记录：自动填写时间、人工补充时间、失败步骤与报告。

| 用例 | 检查结果 |
|---|---|
| 单色两尺码 | 货号、价格库存、图片、已支持属性一致 |
| 双色相同尺码 | 四行组合正确；图片绑定对应颜色，多色测试图能载入 |
| 不同价格库存 | 行序变化也不串行，缺值被拦截 |
| 商品模板A/B | 改A后B不变；套用新编号；未完成模板可恢复编辑；撤销回原资料 |
| 尺码模板 | 类型、单位、单值/区间、上下限保留；更新/删除选中模板不影响其他模板 |
| 身高体重及空表换列 | 空表可调整；两个区间端点回读一致；已有值时保留并停止 |
| 异常与人工接管 | 发现差异后原页修正并重新核对；验证码后不自动重复提交 |

验收结束仅记录实际缺陷，不把平台审核时间算成自动填表时间。

## 使用后优先考虑

1. **提高录入效率**：经用户明确操作批量设置同价或库存、属性下拉选项、必填项定位。不能默认所有规格有库存。
2. **模板管理加强**：标题搜索、使用次数、历史版本、恢复误删和整套备份导出。当前已有基本增改删和最近删除快照。
3. **扩大图片支持**：长详情图、上传前本地压缩、已有素材补传。需要针对现有素材避免重复上传。
4. **更多尺码与类目**：更多平台字段、其他女装类目，需要按具体页面逐类确认。

## 后续独立版本

- 逐款流程稳定后再做批量队列，明确每款结果及失败后继续方式。
- 先接供应商数据导入，再考虑照片识别和文案生成；库存、成分、售价仍由可信来源确认。
- AI模特、视频、跨平台与自动发布单独立项，不与当前MVP验收混在一起。

以上是候选工作，没有承诺全部自动开工。下一步优先级应由真实使用中最耗时的步骤决定。
