# 自动创建规格矩阵并填写 SKU（2026-09-08）

## 本次完成

新命令 `pdd:prepare-skus` 在已有货号的新建 T 恤页执行：

```text
校验页面、货号与计划
→ 检查已有规格和数据
→ 切换中国码
→ 精确选择颜色并核对弹窗选择
→ 确认颜色进入规格区
→ 勾选尺码并逐项回读
→ 按颜色＋尺码核对生成的完整行集合
→ 调用已有 SKU 数值/启停执行器
→ 停在保存前
```

`pdd-matrix-dom.mjs` 读取规格区和颜色弹窗，返回准确的元素供 Playwright 操作。颜色以实际 `el_color_selection_panel` 标记和 `colorV2_colorOption__` 类名前缀限定，排除同名色系标题；已选、禁用状态分别读取对应前缀，不绑定构建版本后缀。颜色名称使用可见文本，不把内嵌 style 的 CSS 文本算入名称。

`pdd-matrix-adapter.mjs` 编译矩阵、保护已有数据、验证生成结果并串联 `executeSkuPlan`。不会点击保存或发布。

## 使用方式

先准备空白规格区的新建 T 恤编辑页，填写与计划相同的货号（可先用文档 13 的基础填写命令）。示例货号是 `AUTO-MATRIX-20260908-01`，仅用于未提交编辑页测试。

```bash
# 只读预检；不打开颜色弹窗或勾选规格
npm run pdd:prepare-skus -- examples/pdd-matrix-smoke.json

# 创建矩阵并填写价格库存等字段；仍不保存或发布
npm run pdd:prepare-skus -- examples/pdd-matrix-smoke.json --apply
```

命令使用独立 Chrome profile；在窗口登录、进入指定店铺的新建 T 恤编辑页并核对货号后回终端按 Enter。只能存在一个待操作商品编辑页；占用同一 profile 的其他自动化窗口应先关闭。

输出：`output/real-matrix-fill/<时间>/report.json`。成功状态为 `matrix_and_sku_verified`，仅证明颜色尺码矩阵和 SKU 数值/启停这一子集通过。`fullProductVerified=false`，主图、详情图、尺寸、属性和物流未因此获得验证。

默认预检只能检查当前可见结构和数据条件；尚未打开的颜色选项、切换码制后的尺码选项及尚未生成的表格在 unverified 中列出。预检通过不代表后续创建一定成功。执行失败返回 steps/before 等部分结果，保留页面供检查，不自动撤销或重试。

## 支持范围与数据保护

- 当前只支持明确指定中国码、平台已有的标准颜色与尺码。
- 直接计划使用 `scope=pdd-tshirt-matrix-v1` 和 `sizeSystem=中国码`，SKU 字段与文档 14 一致。
- 也支持 ProductPackage，复用 SKU 编译桥接，同时要求 `listing.sizeConfiguration.system=cn`。
- 当前只生成完整颜色×尺码矩阵。黑色 S/M、白色只有 M 等稀疏组合在任何操作前拒绝，不补出不存在的 SKU。后续需确认平台逐颜色尺码排除/移除机制后再扩展。
- 已有矩阵完全一致时直接复用，避免重建丢失价格库存。
- 需要改变矩阵但已有 SKU 数据、图片或尺寸表数值时停止；也不自动删除多余颜色/尺码。
- 切换码制要求尚未选择颜色、尺码；已有选择时不会猜测换码关系。
- 每次改变矩阵前再次检查是否出现人工填写值，发现新增数据停止。
- SKU 数据保护只检查实际 tbody 数据行，不将“全部颜色分类”等批量筛选框当作已填写库存。
