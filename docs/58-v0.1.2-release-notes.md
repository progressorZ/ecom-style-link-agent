# v0.1.2 Beta 发布说明

这是拼多多女装 T 恤单款上新助手的预发布版本。项目计划容纳多个独立电商表单 App；本次真正可运行的只有拼多多中国站女装 T 恤单款辅助填表。

## 本次变化

- Windows x64 ZIP 恢复为完整离线包，内置经过 SHA-256 校验的 Node.js v24.15.0 官方运行文件和运行依赖。用户完整解压后无需联网下载依赖。
- 移除 Windows 首次启动时的 PowerShell 下载流程。运行文件缺失时明确提示检查解压结果和系统保护历史。
- Windows 和 macOS 分别提供独立 ZIP 与 SHA-256 文件，不能混用旧版 data 以外的运行文件。
- 固定源码依赖版本，避免未来安装时因 `latest` 漂移。
- 将含店铺身份、商品编号和真实商品图片的后台截图排除在 Git 仓库之外。

## 使用范围与限制

- 单店铺、单款女装 T 恤；支持多颜色、多尺码、属性、价格库存、尺码表、三类图片、发货设置和草稿核对。
- 需要商家本人登录拼多多；商家页面和验证码需要网络，最终发布由商家手动完成。
- 需要系统已安装 Google Chrome；Windows 可使用 Microsoft Edge。浏览器不随包提供。
- 当前 Adapter 为 Beta，平台页面变化可能导致填表停止。macOS 通用包仍为 Experimental；Windows v0.1.2 还需真实 Windows 机器启动确认。

## 下载资产

- `pdd-womenswear-tshirt-v0.1.2-windows-x64.zip`
- `pdd-womenswear-tshirt-v0.1.2-windows-x64.zip.sha256`
- `pdd-womenswear-tshirt-v0.1.2-macos-universal.zip`
- `pdd-womenswear-tshirt-v0.1.2-macos-universal.zip.sha256`

建议从 GitHub Release 页面直接下载并核对 SHA-256。不要通过会删除或改写 ZIP 内可执行文件的聊天软件转发压缩包。使用后的 `data` 目录含个人资料和浏览器登录状态，不得上传或分享。

## 构建说明

用户运行 Windows ZIP 不下载依赖；维护者生成 Windows ZIP 时，打包脚本会从 Node.js 官网下载运行文件、校验固定 SHA-256，并把它放进发行包。
