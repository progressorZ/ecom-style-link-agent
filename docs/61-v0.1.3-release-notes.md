# v0.1.3 Beta 发布说明

本版本修复拼多多女装 T 恤免安装发行版的本机接口连接。此前开发模式由 Vite 转发 `/api/live`，而 ZIP 中的静态服务器没有对应代理，导致网页能够打开但无法读取或写入本机工作台 API。

## 修复

- 发行版静态服务器同源转发 `/api/live/*` 到只监听 `127.0.0.1` 的本机后台。
- 保留 Origin、Content-Type 和后台现有的本机来源校验，不开放远程访问。
- Windows 与 macOS 构建在生成 ZIP 前自动使用全新数据目录启动，验证网页、API 读取、JSON 写入和进程清理。
- 干净启动验证会通过网页端生成一个临时货号，结束后恢复发行目录原始 `data` 内容。
- 前端测试排除历史 `release/` 目录，避免第三方依赖测试污染源码检查结果。

- `pdd-womenswear-tshirt-v0.1.3-windows-x64.zip`
