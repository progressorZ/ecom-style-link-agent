# 首次真实草稿保存与重开（2026-09-10）

## 已发生的动作

本轮首次对真实商家后台中的虚构测试商品 `AUTO-MATRIX-20260908-02` 点击一次“保存草稿”。标题包含“勿上架”。保存前独立回读34项匹配、0项差异、3项素材待核实，并写入本地操作意图及输入、配置、报告副本。

平台随后明确显示“保存成功! 提交商品信息且发布成功后方可生效”。没有点击提交并上架。

在新的浏览器标签页打开原先已经观察到的精确编辑地址。新页面加载出同一货号、标题与SKU；展开物流服务区后重新执行独立核对。当前应以重开标签页8作为后续测试页面，原标签页2保留保存成功提示。

## 重开后发现并修复的差异

1. 满件折扣保存前为输入框，重开后为 `.price-text` 摘要“满2件 9.4 折修改”。独立阅读器新增严格摘要解析；执行器仍要求实际可编辑控件，不会对摘要执行填值或静默跳过。
2. 运费选择从“其他模板”归一化成推荐模板。模板名称、所有包邮地区、付费地区和首续件费用、不配送地区均相同。业务核对改为配送类型＋模板名称＋完整规则，选择分支保存在 presentation 字段中。仍会拒绝费用变化、地区变化、同城配送差异或空规则。
3. 主图URL不变，两个SKU图及详情图从临时地址改为正式CDN地址。目标行及图片数量保留，但不能仅凭URL形态断言内容相同。尝试无登录下载对比返回401，未继续尝试提取登录信息；素材内容确认保留。

`output/playwright/real-draft-cycle/test-2026-09-10/` 包含：

重开后34项字段匹配、0项差异、0项不可读，3项素材仍待核实。店铺前后身份匹配，输入和执行指纹与保存前一致。此次证明了受支持字段的真实保存重开，不等于完整草稿或上架验收；fullDraftVerified、fullProductVerified 和 published 均为 false。

此前文档中“未保存草稿”是历史状态，从本轮起已不再代表最新状态。
