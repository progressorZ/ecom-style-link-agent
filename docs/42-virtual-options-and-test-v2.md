## 实现

新增pdd-select-option.mjs并接入单选属性执行器。先检查当前精确选项；未找到时定位唯一可见listbox内具有auto/scroll溢出的滚动容器，从顶部开始按视窗75%步长移动，等待渲染后重新查找。最多40轮，每轮核对页面身份；到末尾、限次、歧义或目标缺失停止，不选近似项。

仅滚动已观察的页面DOM，不读内部缓存或隐藏接口。品牌精确选项也复用此路径，但远程搜索、分页和多层滚动未支持。异步渲染更慢的页面可能保守失败，需要现场证据扩展，不能承诺任意虚拟列表。
