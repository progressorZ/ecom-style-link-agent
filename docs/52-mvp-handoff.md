# 当前 MVP 交付状态

更新：2026-09-12。当前操作以根目录《使用说明.md》为准；本文替换此前过时的手填编码、仅肩胸单值等交付描述。

## 已实现

本地单款女装T恤表单接入真实执行器，包含属性、颜色尺码矩阵、价格库存、三类图片、发货及全局运费配置。货号与规格编码自动生成。

商品模板支持多模板标题、保存当前未完成资料、套用、更新、删除及一次套用撤销。尺码模板支持保存、套用、更新、删除；成衣实测与身高体重表型分别记忆字段和区间。复制、模板套用保留业务资料，新的商品生成新身份并重新确认。

平台空尺码表可调整列、切换区间并回读上下限；已有尺寸阻止自动改列。颜色图片预览和移除、提前数量检查、多颜色测试图片复用均已接入。图片限制为主图/详情图各10张、颜色最多10种、总规格40个；颜色图片可明确复用文件，主图/详情图仍禁止组内重复。

普通用户不需要JSON。删除模板保留图片和当前商品，并保存最近一次删除前的列表快照。

## 边界

一个店铺、本地使用、一次一款T恤。完整颜色×尺码组合；固定促销及服务范围详见使用说明。衣长袖长仅记录和复用，需人工补充。真实图片内容、验证码、额外必填项和最终发布交给人工。

## 验证证据

本地检查覆盖输入/API、模板持久化与删除、共享颜色图、数量限制、规格隔离、确认失效、区间读写、空表换列和界面撤销。具体当前测试结果以命令输出为准，不把历史测试数量当成完成度。

历史受控商家测试见 `output/acceptance/2026-09-10/repair-and-save.json`，曾有34项匹配、3项素材待人工核实；该记录不验证之后新增功能。三案例记录 `output/acceptance/2026-09-12/status.json` 没有完整通过结果。最新实店验收按用户要求由用户操作，本轮不访问商家页面。
