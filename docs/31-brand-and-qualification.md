## 品牌

真实品牌框为 Beast 单选组件，空值展开时包含“无品牌/无注册商标”和多个命名品牌。`product.brand=null` 或缺失只代表资料未知，不自动映射到无品牌。用户明确提供非空精确平台名称时，统一编译增加 brand 步骤，位于 basic 之后，执行核心沿用属性单选模块。

品牌输入即使已显示预期文字，执行仍强制打开并选择精确可见 option，再关闭回读，以免把搜索字符串当成选择结果。当前支持已加载且唯一的可见选项；搜索请求、虚拟长列表、品牌申请或授权上传尚未实现，目标不在可见选项中即停止。

```bash
npm run pdd:fill-attributes -- examples/pdd-brand-smoke.json
npm run pdd:fill-attributes -- examples/pdd-brand-smoke.json --apply
```

默认预检不选项。示例为虚构测试商品，不能证明真实衣服无品牌。`--apply` 检查货号和页面身份后操作品牌，不保存或发布。
