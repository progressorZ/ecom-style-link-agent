# 示例说明

- `product-package.json`：结构完整的虚构商品，三个实际 SKU，米白 S 不存在；总库存 65 件，售价范围 129～139 元。
- `variants.csv`：与 JSON 的 Variant/Offer 对应，按真实 T 恤页面区分拼单价和单买价；CSV 价格单位为元，JSON 金额单位为分。
- `media/...` 只是占位路径，不包含商品图片。不要拿流程说明截图代替商品主图。
- demo 店铺、类目和物流均未绑定真实平台，物流确认 false；即使结构校验通过也必须被执行预检阻塞。
- JSON 中 approved 和 confirmed=true 仅用于演示状态结构，不是实际用户审核记录。导入到应用时不能信任文件自行声明的确认，应将其视为待核实的导入信息，由当前用户/可信业务流程重新确认。
- Schema 仅验证结构；唯一键、引用、SKU 颜色绑定、尺寸列关系、时间有效性和平台规则由业务校验器实现。
