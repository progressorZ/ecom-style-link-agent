拼多多女装 T 恤上新助手 macOS 便携版

作用：
把女装 T 恤的标题、属性、颜色尺码、价格库存、尺寸表和图片录入一次，助手自动填写拼多多商品编辑页并回读核对。你负责登录、验证码、检查商品并点击最终发布。

完整流程：
准备商品资料 → 工作台录入或复用模板 → 登录拼多多 → 自动填写并核对 → 手动发布

1. 完整解压 ZIP，不要在压缩包预览中运行。
2. 双击 Start-PDD-Assistant.command。
3. 如果系统首次阻止打开，请在“系统设置 → 隐私与安全性”核对来源后选择允许；不要关闭系统安全功能。
4. 在工作台填写真实商品资料；第一次不会填时，先点击“载入完整初始示例”，再逐项替换。
5. 点击“检查资料并载入”和“打开商家浏览器”。当前浏览器自动化需要 Google Chrome。
6. 登录拼多多，进入“女装/女士精品 → T 恤 → T 恤”的新商品编辑页。
7. 回到工作台点击“填写并核对”。验证码、滑块和最终发布由本人处理。

一个 ZIP 同时支持 Apple Silicon（M 系列）和 Intel Mac，启动脚本会自动选择运行时。
个人商品资料、图片、报告和专用浏览器登录状态保存在 data 文件夹。更新同一个 App 时备份 data；不要将使用后的 data 分享给别人。
